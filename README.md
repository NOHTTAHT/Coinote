# Coinote

แอปจดรายรับรายจ่ายสำหรับ iPhone (เว็บแอป ติดตั้งลงหน้าจอได้) อ่านสลิปโอนเงินให้อัตโนมัติผ่าน Shortcuts

- รายการรายวัน สรุปรายเดือนตามหมวดหมู่
- บัญชีธนาคาร e-Wallet เงินสด และโอนข้ามบัญชี
- บัตรเครดิต: จ่ายเต็ม ผ่อนชำระ สมาชิกรายเดือน ยอดต้องชำระแต่ละรอบ
- หนี้สินและงวดผ่อน
- นำเข้าประวัติจาก Wallet Story (CSV)
- อ่านสลิป K PLUS, ttb, CIMB, TrueMoney, ShopeePay และ SMS บัตรเครดิต จัดหมวดให้เอง และจำหมวดที่แก้

ไฟล์: `index.html` ตัวแอป, `config.js` ค่าเชื่อม Supabase, `supabase/setup.sql` ฐานข้อมูลและตัวอ่านสลิป
วิธีติดตั้ง: ดู [SETUP-TH.md](SETUP-TH.md)
